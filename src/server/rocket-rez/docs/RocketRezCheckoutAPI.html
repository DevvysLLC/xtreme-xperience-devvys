Overview

This guide provides comprehensive instructions for implementing the RocketRez Headless Checkout system on your frontend application. It covers all necessary API integrations, payment processing, and client-side requirements.

Note: This guide assumes you have received OAuth credentials from RocketRez. Contact support if you need assistance obtaining these credentials.

1. Prerequisites & Dependencies

Required JavaScript Libraries

Stripe.js v3 REQUIRED
<script src="https://js.stripe.com/v3/"></script>

Stripe.js is required for secure payment processing. This library handles sensitive card data and ensures PCI compliance.

2. Authentication & Configuration

OAuth 2.0 Token REQUIRED

All API calls require OAuth 2.0 authentication using the client credentials flow.

POST {apiBaseUrl}/oauth2/token

Request

{
  "client_id": "your-client-id",
  "client_secret": "your-client-secret",
  "scope": "read_orders read_products read_carts write_carts",
  "grant_type": "client_credentials"
}

Headers

{
  "Content-Type": "application/json"
}

Response

{
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",
    "expires_in": 3600
  }
}
Important: Store the access_token for use in subsequent API calls. The token expires after the time specified in expires_in (seconds).

User GUID Management

Each user session requires a unique GUID for tracking cart operations.

Implementation Steps:

  1. Generate a UUID using crypto.randomUUID()
  2. Convert to Base64 format
  3. Store in localStorage for session persistence
  4. Include in RocketRezUserGuid header for all cart operations

Example Implementation

function generateUserGuid() {
  const guid = crypto.randomUUID();
  const userGuid = btoa(
    guid.replace(/-/g, '')
      .match(/.{2}/g)
      .map(byte => String.fromCharCode(parseInt(byte, 16)))
      .join('')
  );
  localStorage.setItem('headlessUserGuid', userGuid);
  return userGuid;
}

3. Cart Management Flow

Step 1: Create Cart

POST {apiBaseUrl}/headless/cart

Headers

{
  "Authorization": "Bearer {jwtToken}",
  "Content-Type": "application/json"
}

Request Body

{
  "lineItems": [
    {
      "id": 1,
      "type": "Event",
      "quantity": 1,
      "scheduleId": 10325,
      "rateId": 1,
      "rateType": "Adult"
    }
  ]
}
Item Types
  • Event - Event tickets
  • Retail - Retail products
  • Giftcard - Gift cards
  • Unknown - Other items

Response

{
  "data": {
    "cart": {
      "id": "cart-id-123",
      "lineItems": [...],
      "total": 100.00
    },
    "cartToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userGuid": "base64-encoded-guid"
  }
}
Critical: Store cartId, cartToken, and userGuid - they are required for all subsequent operations!

Step 2: Add Line Items OPTIONAL

Add additional items to an existing cart.

POST {apiBaseUrl}/headless/cart/lineitems

Headers

{
  "Authorization": "Bearer {cartToken}",
  "RocketRezUserGuid": "{userGuid}",
  "Content-Type": "application/json"
}

Request Body

{
  "lineItems": [
    {
      "id": 1,
      "type": "Event",
      "quantity": 1,
      "scheduleId": 10325,
      "rateId": 1,
      "rateType": "Adult"
    }
  ]
}

Step 3: Update Line Items OPTIONAL

Modify quantity or other properties of existing line items.

PATCH {apiBaseUrl}/headless/cart/lineitems/{lineItemId}

Headers

{
  "Authorization": "Bearer {cartToken}",
  "RocketRezUserGuid": "{userGuid}",
  "Content-Type": "application/json"
}

Request Body

{
  "quantity": 2,
  "scheduleId": 10325,  // optional
  "rateId": 1,          // optional
  "rateType": "Adult"   // optional
}
Note: All fields except quantity are optional. Include only fields you want to update.

Step 4: Delete Line Items OPTIONAL

Remove items from the cart.

DELETE {apiBaseUrl}/headless/cart/lineitems/{lineItemId}

Headers

{
  "Authorization": "Bearer {cartToken}",
  "RocketRezUserGuid": "{userGuid}"
}

5. Payment Processing

Step 1: Get Gateway Client Secret

Retrieve a client secret from your payment gateway (e.g., Stripe) to initialize payment.

GET {apiBaseUrl}/headless/payment/gateway-client-secret

Query Parameters

  • paymentMethodId REQUIRED - Your payment method ID
  • isCardOnFile REQUIRED - true or false (Leave as false for now as card on file is not implemented in Headless yet)
  • gatewayPaymentMethod OPTIONAL - e.g., "card"

Headers

{
  "Authorization": "Bearer {cartToken}",
  "RocketRezUserGuid": "{userGuid}"
}

Example Request

GET {apiBaseUrl}/headless/payment/gateway-client-secret?paymentMethodId=66&isCardOnFile=false

Response

{
  "result": {
    "data": {
      "clientSecret": "pi_xxxxxxxxxxxxx_secret_xxxxxxxxxxxxx"
    }
  }
}
Important: Store the clientSecret - it's required for Stripe payment confirmation.

Step 2: Integrate Payment Iframe

The RocketRez Headless Client provides an iframe for secure payment processing.

Load the Iframe

<iframe id="checkout-iframe" src="{iframeUrl}" frameborder="0"></iframe>

Initialize Communication

const iframe = document.getElementById('checkout-iframe');

iframe.onload = function() {
  iframe.contentWindow.postMessage({
    type: 'INIT',
    cartId: cartId
  }, '*');
};
The React App will respond to the Parent window with a message of type READY at which point you can send a PROCESS_PAYMENT message type with the appropriate information (next step).

Step 3: Process Payment via Iframe

Send payment details to the iframe for processing.

Example Payment Request

iframe.contentWindow.postMessage({
  type: 'PROCESS_PAYMENT',
  clientSecret: clientSecret,
  cartToken: cartToken,
  userGuid: userGuid,
  paymentRequest: {
    PaymentMethodId: 66,
    CartId: cartId,
    PaymentTotal: 100.00,
    RecaptchaToken: null,  // optional
    FirstName: "John",
    LastName: "Doe",
    Email: "customer@example.com",
    CompanyName: null,
    MobilePhoneNumber: null,
    HomePhoneNumber: null,
    BillingAddress: {
      Address1: "123 Main St",
      Address2: null,
      City: "City Name",
      CountryShortName2: "US",
      ProvinceId: null,
      PostalCode: "12345"
    },
    SMSConsent: false,
    CreditCard: {
      Type: null,
      Cvv: null,
      Expiry: null,
      Name: "John Doe",
      Number: null
    },
    allowSecondaryPayments: false,
    SecondaryPayments: []
  }
}, '*');

Step 4: Listen for Payment Events

Handle responses from the iframe.

window.addEventListener('message', function(event) {
  // Filter out Stripe internal messages
  if (event.origin && event.origin.includes('.stripe.com')) return;

  switch(event.data.type) {
    case 'READY':
      // Iframe is ready for communication
      console.log('Iframe ready');
      break;

    case 'PAYMENT_AUTH_SUCCESS':
      // Stripe payment authorization successful
      console.log('Payment authorized!');
      console.log('Payment Intent ID:', event.data.paymentIntentId);
      console.log('Status:', event.data.status);
      // Show loading indicator - order is being created
      break;

    case 'PAYMENT_AUTH_ERROR':
      // Stripe payment authorization failed
      console.error('Payment authorization failed:', event.data.error);
      // Show error message to user
      break;

    case 'PAYMENT_SUCCESS':
      // Payment fully processed and order created
      console.log('Payment complete! Order created.');
      console.log('Payment Intent ID:', event.data.paymentIntentId);
      console.log('Order ID:', event.data.orderId);
      console.log('Status:', event.data.status);
      // Redirect to confirmation page
      window.location.href = `/confirmation?orderId=${event.data.orderId}`;
      break;

    case 'PAYMENT_ERROR':
      // Payment processing or order creation failed
      console.error('Payment processing failed:', event.data.error);
      // Show error message to user
      break;

    case 'UNKNOWN_MESSAGE_TYPE':
      // Iframe received an unrecognized message
      console.warn('Iframe received unknown message type');
      break;
  }
});

PostMessage Communication Reference

The parent window and iframe communicate via the postMessage API. Below are all message types currently in use:

Message Type Sender Description Data Properties
INIT Parent → Iframe Initialize the iframe with cart information cartId
READY Iframe → Parent Iframe is loaded and ready to receive messages None
PROCESS_PAYMENT Parent → Iframe Send payment details to process payment clientSecret, paymentRequest, cartToken, userGuid
PAYMENT_AUTH_SUCCESS Iframe → Parent Stripe payment authorization successful (payment intent confirmed) paymentIntentId, status
PAYMENT_AUTH_ERROR Iframe → Parent Stripe payment authorization failed error (error message)
PAYMENT_SUCCESS Iframe → Parent Payment fully processed and order created successfully paymentIntentId, orderId, status
PAYMENT_ERROR Iframe → Parent Payment processing or order creation failed error (error message)
UNKNOWN_MESSAGE_TYPE Iframe → Parent Iframe received an unrecognized message type None
Payment Flow: The typical successful payment flow is: INIT → READY → PROCESS_PAYMENT → PAYMENT_AUTH_SUCCESS → PAYMENT_SUCCESS

6. Error Handling

Common Error Scenarios

Error Type Possible Causes Handling
401 Unauthorized Invalid or expired token Refresh OAuth token and retry
404 Not Found Invalid cart ID or line item ID Verify IDs and create new cart if needed
400 Bad Request Missing required fields or invalid data Validate input and show user-friendly errors
Network Error Connection timeout or server down Show retry option or maintenance message
Stripe Error Card declined, insufficient funds, etc. Display Stripe error message to user

Example Error Handling

async function createCart(lineItems) {
  try {
    const response = await fetch(`${apiBaseUrl}/headless/cart`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${jwtToken}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ lineItems })
    });

    const data = await response.json();

    if (!response.ok) {
      throw new Error(data.errorMessage || 'Failed to create cart');
    }

    return data;
  } catch (error) {
    console.error('Error creating cart:', error);
    showErrorMessage('Unable to create cart. Please try again.');
    return null;
  }
}

7. Security Considerations

Client-Side Security

Never expose OAuth client secrets or API keys in client-side code!
  • Use environment variables or secure configuration management
  • Validate all postMessage events by checking event.origin

Example Origin Validation

window.addEventListener('message', function(event) {
  // Only accept messages from trusted origins
  const trustedOrigins = [
    'https://your-domain.com',
    'https://pr5532.dev.aws.rocket-rez.com'
  ];

  if (!trustedOrigins.includes(event.origin)) {
    console.warn('Rejected message from untrusted origin:', event.origin);
    return;
  }

  // Process the message
  handlePaymentMessage(event.data);
});

HTTPS

Always use HTTPS in production. Stripe requires HTTPS for payment processing.

Token Storage

  • Store tokens securely
  • Use sessionStorage or secure cookies (not plain localStorage in production)

9. Complete Integration Example

Full Checkout Flow

// 1. Get OAuth Token
async function authenticate() {
  const response = await fetch(`${apiBaseUrl}/oauth2/token`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      client_id: clientId,
      client_secret: clientSecret,
      scope: 'read_orders read_products read_carts write_carts',
      grant_type: 'client_credentials'
    })
  });
  const data = await response.json();
  return data.data.access_token;
}

// 2. Create Cart
async function createCart(jwtToken, lineItems) {
  const response = await fetch(`${apiBaseUrl}/headless/cart`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${jwtToken}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ lineItems })
  });
  const data = await response.json();
  return data.data;
}

// 3. Add Contacts
async function addContacts(cartToken, userGuid, contactInfo) {
  const response = await fetch(`${apiBaseUrl}/headless/cart/contact`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${cartToken}`,
      'RocketRezUserGuid': userGuid,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ contacts: [contactInfo] })
  });
  return await response.json();
}

// 4. Get Client Secret
async function getClientSecret(cartToken, userGuid, paymentMethodId) {
  const response = await fetch(
    `${apiBaseUrl}/headless/payment/gateway-client-secret?paymentMethodId=${paymentMethodId}&isCardOnFile=false`,
    {
      headers: {
        'Authorization': `Bearer ${cartToken}`,
        'RocketRezUserGuid': userGuid
      }
    }
  );
  const data = await response.json();
  return data.result.data.clientSecret;
}

// 5. Complete Checkout Flow
async function completeCheckout() {
  try {
    // Step 1: Authenticate
    const jwtToken = await authenticate();

    // Step 2: Create cart
    const cartData = await createCart(jwtToken, [
      {
        id: 1,
        type: 'Event',
        quantity: 2,
        scheduleId: 10325,
        rateId: 1,
        rateType: 'Adult'
      }
    ]);

    const { cart, cartToken, userGuid } = cartData;

    // Step 3: Add contacts
    await addContacts(cartToken, userGuid, {
      isPrimary: true,
      firstName: 'John',
      lastName: 'Doe',
      email: 'customer@example.com',
      phone: '5555555555',
      billingAddress: {
        addressLine1: '123 Main St',
        city: 'City Name',
        postalCode: '12345',
        country: 'USA'
      }
    });

    // Step 4: Get client secret
    const clientSecret = await getClientSecret(cartToken, userGuid, 66);

    // Step 5: Load iframe and process payment
    loadIframe(cart.id, clientSecret, cartToken, userGuid);

  } catch (error) {
    console.error('Checkout error:', error);
    showErrorMessage('Checkout failed. Please try again.');
  }
}
