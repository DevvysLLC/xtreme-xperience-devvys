# Core Form

A reusable form component that renders form fields from DatoCMS FormRecord data.

## Usage

```tsx
import { CoreForm } from '@/components/core-form'

<CoreForm data={formData} />
```

## Features

- Renders form fields dynamically from CMS data
- Handles form submission states (idle, submitting, success, error)
- Displays success/error messages with optional CTA buttons
- Responsive grid layout for form fields
